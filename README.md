# Dragon Ball: A Galeria dos Guerreiros Mais Poderosos! 🐉💥

Prepare-se para entrar no universo de Dragon Ball e conhecer os guerreiros mais fortes do universo 7! 
Este projeto é uma galeria interativa que permite que você explore e descubra informações sobre os seus personagens favoritos. 
É hora de aumentar o seu Ki!

---

## Sobre o Projeto

Este projeto é um **carrossel de imagens e informações** dos personagens de Dragon Ball. 
A ideia é ter uma experiência de navegação fluida, onde você pode clicar nos botões para mudar a imagem de fundo, o nome e a descrição do personagem. 
É uma maneira divertida de revisitar os heróis e vilões que marcaram o anime.

---

## Tecnologias

Para construir esta jornada épica, utilizamos:

* **HTML**: A base da nossa galeria, com a estrutura dos botões, imagens e as informações de cada personagem.
* **CSS**: O poder estético! Ele estiliza o carrossel, as transições, os efeitos de destaque e deixa a interface com a cara de Dragon Ball.
* **JavaScript**: A força motriz que faz tudo funcionar! Ele detecta os cliques nos botões, atualiza a imagem e o texto na tela, criando uma experiência interativa e dinâmica.

---

## Como Usar

É mais fácil do que se transformar em Super Saiyajin!

1.  **Clone este repositório** para o seu computador.
2.  **Abra o arquivo `index.html`** no seu navegador.
3.  No final da tela, você verá uma série de **botões circulares**.
4.  **Clique em qualquer um dos botões** para mudar a imagem de fundo e ver as informações do personagem correspondente.

---

## Funcionalidades

* **Carrossel Interativo**: Navegue entre os personagens com um simples clique.
* **Informações Dinâmicas**: O nome e a descrição do personagem mudam automaticamente junto com a imagem.
* **Animações Suaves**: A troca de imagens e o destaque dos botões são feitos com transições elegantes.
* **Design Temático**: A interface é inspirada no universo de Dragon Ball, com cores e fontes que remetem ao anime.
